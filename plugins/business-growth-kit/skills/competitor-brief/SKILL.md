# Competitor Brief

Use this skill when the user asks for competitor research, competitive positioning, sales battlecards, SWOT analysis, alternative vendor comparison, or market landscape notes.

## Workflow

1. Clarify the comparison frame:
   - Our product, service, or company
   - Competitors or alternatives
   - Target buyer segment
   - Decision criteria
   - Market, region, and price tier if relevant

2. If up-to-date facts are required, browse or use reliable current sources before making claims. Cite sources when using external information.

3. Compare competitors using buyer-relevant dimensions:
   - Positioning and ideal customer
   - Core strengths
   - Common weaknesses or tradeoffs
   - Pricing model if known
   - Product depth and integrations
   - Implementation complexity
   - Support, ecosystem, and trust signals
   - Best-fit and poor-fit scenarios

4. Convert analysis into commercial action:
   - How we should position against each competitor
   - Discovery questions to reveal fit
   - Objection handling notes
   - Differentiation claims that need evidence
   - Risks if the competitor is a better fit

## Output Style

Use a concise brief format. Tables are useful for side-by-side comparisons, but include narrative takeaways so the user knows what to do with the analysis.

## Quality Bar

- Do not overclaim superiority.
- Separate verified facts from inference.
- Flag stale or uncertain information.
- Focus on the buyer's decision, not only feature checklists.
- Include practical sales or strategy implications.
